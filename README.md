# とおいサウナ — バトル版

**喋らずに殴り合うサウナ。**他人を熱くできる。最後まで座っていた人にだけ「ととのった」と出る。記録は残らない。
設計は `勝ち筋.md`。居心地版（何も達成しない版）は `index-居心地版.html` に残してある。

**確かめるのはこの3つ。**

1. **10人集まるか**
2. **2回目を自分からやりたくなるか**（面白いか。1回で終わったら面白くない）
3. **予兆に気づけたか**（運ゲーになっていないか）

**2が折れたらバトルにした意味が無い。**

> 2026-07-26 追記：一人で触って「おもしろくない」と判定された。原因は**行動に報酬が1つも無かったこと**（ロウリュは狙えず匿名で自分にも当たる／決断の間が数十秒空く／負け方が受動的）。
> 対処として**呼吸**を核に入れ、**ロウリュを上段ほど効くようにして狙いを作り、食らった人がすくむようにして手応えを出した**。
> なお**一人で開くと事件が何も起きない**（誰もロウリュを打たない）ので、**評価は必ず2人以上で行うこと。**ブラウザのウィンドウを2つ開けば試せる。

## 遊び方（説明は本来不要。ここは開発用のメモ）

**ゲージは2本ある。**

| ゲージ | 意味 |
| --- | --- |
| **体力** | **熱が高いほど速く減る。戻らない。0になったら出される** |
| **熱** | いまどれだけ熱いか。段で落ち着き先が決まり、水で下がり、ロウリュで跳ね上がる |

**水は熱を下げるだけで体力は戻らない**＝延命であって解除ではない。だから回には必ず終わりと山がある。
数字は出さない。**他人の限界は姿勢で分かる**（熱いと前に屈み、体力が尽きてくるとさらに沈む）。

**常にやっていることは「呼吸」。**画面左下の輪がふくらみ切った瞬間に、**どこでもいいので触れる**。

- 合っている間は**体力の減りが目に見えて遅い**（整え続けると放置の約1.9倍もつ：184秒 対 98秒）
- **ロウリュが降ると呼吸が飛んで、合わせ直しになる。**これが他人の攻撃の本体
- 上段は呼吸が速くて難しい／下段は遅くて楽。乱れているとさらに速くなる
- 連打では稼げない（1周期に判定は1回だけ）

**ここが「他人がいないと成立しない」の実体です。**以前は他人の行動が数値にしか効いていなかったので、居ても居なくても同じでした。いまは他人が自分の操作を直接邪魔します。

操作は3つだけ。すべて画面の下半分。

| 操作 | 何が起きるか |
| --- | --- |
| **ロウリュ** | 全員の熱が上がり**呼吸が飛ぶ**。**上段の人ほど大きく食らう**（上段1.8倍／下段0.35倍）。押した人は誰にも分からないが、**誰に当たったかは見える**（食らった人がすくむ） |
| **水** | 自分の熱を下げる。**桶は1回に3杯だけ。体力は戻らない** |
| **下がる／上がる** | 下段は涼しいがロウリュが打てない。**席が全体の1〜2割しか無いので満席なら下がれない** |

- ロウリュには**予兆が1.8秒ある**。ひしゃくの音がして石が白く光り、輪が広がってから蒸気が降りる。**その間に水をかぶるか下がるかを選ぶ**
- **石が赤熱していたら、誰かが打てる状態**。暗いうちは誰も打てない。つまり「いつ来得るか」は分かり、「誰が打つか」だけが分からない
- 体力が尽きたら出される（**のぼせた**）。ただし**部屋から消えず床で観戦する**
- 15分の開場の中で**4分10秒×3回**（間は50秒）

**一人で生き残れるのは「下段に座って呼吸を整え続ける」だけ**です。上段は呼吸が完璧でも落ちます。そして下段は席が2〜3しかないので取り合いになります。

| 座る場所 | 整え続ける | 半端 | 放置 |
| --- | --- | --- | --- |
| 上段 | 181秒（落ちる） | 135秒 | 110秒 |
| 中段 | 226秒（落ちる） | 164秒 | 131秒 |
| 下段 | **304秒（残る）** | 211秒 | 165秒 |

※ 1回は250秒。他人のロウリュが飛べばどれも早く落ちます

## まず2人で試す（Firebaseも要らない）

**一人で開いても事件は何も起きない。**誰もロウリュを打たないので、円に合わせてタップしながらバーが減るのを見るだけになる。**この製品の中身は他人なので、一人での評価は意味がない。**

**`2人で試す.bat` をダブルクリックする。**2つのウィンドウが開くので、両方で「ふれて入る」を押す。

- 片方で**ロウリュ**を押す → **もう片方の呼吸が乱れて熱が上がる**
- 上段に座っている方が大きく食らう
- これが起きないなら、この製品には存在理由がない

同じPCの窓どうしは BroadcastChannel で繋がる（サーバーもDBも不要）。**複数の端末でやるときは下記の Firebase 設定が必要。**

## いますぐ見る（ひとり・オフライン）

`index.html` をダブルクリックする。他人は出ないが、火・熱・3つの操作・予兆・音・脱衣所は全部動く。

- **`index.html?open=1`** … 開場時刻（毎時00分・30分）を待たずに中に入る
- **`index.html?open=1&fast=1`** … **1回を20秒にする。**手触りを見るのに3分待たなくて済む
- **`index.html`** … 本番どおり。00分〜15分と30分〜45分だけ開く。それ以外は脱衣所

音は**ドアに触れた後**に鳴る（ブラウザの制限。この1タップが音の許可も兼ねている）。

## 10人でやる（本番テスト）

### 1. Firebase Realtime Database を用意する（5分・無料）

1. https://console.firebase.google.com/ で新規プロジェクトを作る（Analytics は不要）
2. 左メニュー **構築 → Realtime Database → データベースを作成**
3. ロケーションは **asia-southeast1**、**テストモードで開始**
4. 表示された URL（`https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`）をコピー
5. `index.html` の先頭 `const DB = "";` に貼る

ルールはこれだけでよい。

```json
{ "rules": { "rooms": { "$room": { ".read": true, ".write": true } } } }
```

**注意：これは誰でも読み書きできる状態。**1回の告知テスト専用と考えて、**終わったらデータベースを削除するか、ルールを `false` に戻す。**

### 2. 置く

`file://` のままでは通信が通らないことがあるので、**GitHub Pages に置く**（既存の `tmk4men.github.io` と同じやり方）。置くのは `index.html` 1枚だけ。

### 3. 告知して集まる

Xで「**23:00 にここに集まります**」と1回だけ投げる。23:00 から15分だけ開く。

### 見るところ

- **体力が半分を切ってから、上段に残るか下段へ逃げるかで迷ったか**（迷わないなら数値のバランスが悪い）
- **石が赤熱した瞬間に身構えたか**（誰かが打てる状態になった＝緊張のピーク）
- **予兆に気づいて水を使えたか**。気づけないなら予兆が弱い（`LOYLY_TELL` を伸ばす）
- 下段が満席で下がれなかった人が出たか（**席の取り合いが起きたか**）
- 1回終わったあと、**言われなくても次の回に残ったか**

### 手触りが合わないときに触る場所

`index.html` の先頭にまとまっている。**ここだけ触れば調整できる。**

| 定数 | 意味 |
| --- | --- |
| `STAM_BASE` | **体力の減る速さ（何秒もつか）。ここが回の長さを決める** |
| `BREATH_HIT` | 呼吸が「合った」と見なす前後の幅（ms）。狭いと歯を食いしばる感じになる |
| `BREATH_FAST` / `BREATH_SLOW` | 上段／下段の呼吸の周期（秒）。差が大きいほど段の選択が重くなる |
| `CALM_RELIEF` | **腕でどれだけ差がつくか。**大きいほどリズムの上手さが効く |
| `DISTURB_MS` | ロウリュ後、呼吸が乱れている時間 |
| `HEAT_K` | **熱の上がる緩さ。**0.013＝時定数77秒。小さいほどじんわり（初期は0.045だった） |
| `ROUND_MS` / `GAP_MS` | 250秒＋50秒＝300秒。15分の開場にちょうど3回入る。**`HEAT_K` を緩めたら1回も伸ばす**（短いままだと下段に籠るだけで必ず残れてしまう） |
| `HEAT_DROP` | 上段と下段の落ち着き先の差。**大きいほど下段が安全になる** |
| `LOYLY_HEAT` | ロウリュ1発で乗る熱 |
| `LOYLY_TELL` | 予兆の長さ。**短いと運ゲー寄り、長いと緊張が抜ける** |
| `LOYLY_ROOM` | ストーブが冷えるまでの時間。短いと地獄になる |
| `WATER_MAX` / `WATER_COOL` | 桶の数と1杯の効き |
| `ROUND_MS` / `GAP_MS` | 1回の長さと回の間 |

## 装備（MVPには入れていない）

`EQUIPMENT = false`。**先にコアが面白いかを確かめる。**入れるときも「暑さ耐性」にはしない——耐性を上げると「何もしないのが最適」になり、バトルにした目的と真逆になる。全部トレードオフにする（`勝ち筋.md` 8 の表）。

## 見た目（2026-07-26 に作り込んだ）

**絵文字は一切使わず、すべて Canvas のベクター描画。**外部画像もフォントも読み込まない。

- **人** — 頭・首・肩から腰へ細くなる胴・膝に置いた腕・前へ垂れる脛。**3人に2人はサウナハットをかぶっている**（一目でサウナに見える）。姿勢は人ごとに少し違う
- **読み取れる状態** — 熱いと前に屈む／体力が尽きてくるとさらに沈む／**限界が近い人は輪郭が赤く揺れる**／ロウリュを食らうとすくむ（上段の人ほど大きく）
- **壁は横張り**（フィンランドのサウナに合わせた）。板の上端に光、下端に影。四隅に柱
- **段** — 天面・前面・スラットの継ぎ目・落ち影で厚い板に見せる
- **ストーブ** — 鉄の胴に吸気の隙間、山に積んだサウナストーン、脚、床の影
- **桶とひしゃく** — 予兆の間は**ひしゃくが持ち上がって傾く**。合図が「光」ではなく「動作」になる
- **ボタン** — ひしゃく／桶／山形の自前アイコン。押せるものだけ上端が光る
- **席は中央へ寄せる** — 端まで広げると人数がいても閑散として見えるため

## 作りの要点

- **単一HTML。**ライブラリもビルドも無い。絵文字は使わず全て Canvas のベクター描画
- **同じ火の保証：** 炎は乱数ではなく `floor(サーバー時刻/33ms)` を種にした決定的ノイズ。**全端末で同じ形の炎が同じ瞬間に揺れる**（映像は送っていない）
- **通信は3種類だけ：** presence（2秒ごとの心拍・7秒で退室とみなす）／ロウリュ／サーバー時刻。1人あたり毎秒数バイト
- **音は全て生成**（ストーブの唸り・ドア・ジュッ・衣擦れ）。衣擦れは全端末で同じ人が同じ瞬間に動くので、**同じ部屋の音**になる
- **嘘をつかない：** 人数は実数。サクラも「平均人数」も入れていない。席は必ず人数より多く作る

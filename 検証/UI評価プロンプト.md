添付は「とおいサウナ」というスマホ向けWebゲームのUIです。**見た目とUXだけ**を厳しく評価してください。ゲームバランスや企画の話は不要です。

## 何のアプリか

オンラインの共在サウナ。薄暗いサウナ室に他人と一緒に座り、喋らず、**ロウリュ（ストーブに水をかける）で他人を熱くする**。熱が高いほど体力が減り、0で退場。最後まで残った1人に「ととのった」と出る。

## 画面の説明（添付の順）

1. `1-entrance.png` — 入口。ドアに触れて入る
2. `2-room.png` — サウナ室。9人。石が赤熱＝誰かがロウリュを打てる状態
3. `3-tell.png` — ロウリュの予兆（1.8秒）。石が白く光り、ひしゃくが持ち上がって傾く。この間に「水」か「下がる」で対処する
4. `4-hit.png` — 着弾。蒸気が上から降りてくる
5. `5-crowd-hot.png` — 満室21人＋高温。空気が歪む
6. `6-locker.png` — 閉場中の脱衣所。毎時00分と30分にしか開かない

画面下の3ボタンが全操作。左上「残り N人」、右上が室温。バーは上が体力、下が熱。左下の円は呼吸のリズム（円が重なった瞬間にどこでもタップすると体力の減りが緩む）。

## 制約（変えられない前提）

- **単一のHTMLファイル。外部画像・外部フォント・ライブラリ一切なし。**すべて Canvas 2D のベクター描画
- **絵文字を使わない。**アイコンは自前で描く
- 縦持ち・片手・暗所・就寝前に使う。主要操作は画面下半分、タップ領域は44pt以上
- 色はダーク＋暖色アクセント1色を基本にしている
- コードは同じディレクトリの `index.html`（描画は drawRoom / drawStove / drawPerson / drawBreath / drawControls）

## 聞きたいこと

**1. 素人っぽく見える点を、具体的に、優先度順に。**「もっと洗練させる」のような一般論ではなく、「どの要素のどの数値・形状がどう見えているから安っぽい」というレベルで。

**2. 人物の描画。**いま影絵＋火側のリム光で描いている。プロポーション・姿勢・シルエットの読みやすさに問題があれば指摘してください。

**3. 情報設計。**3ボタン＋2本のバー＋呼吸の円＋上部の数値。多すぎ／読み取れない／視線が飛ぶ、などあれば。特に「1.8秒で反応する」ことが本当に可能な提示になっているか。

**4. Canvas 2Dのままで実現できる具体的な改善案を5つまで。**各案に「どう描くか」を1〜2行で。実装できない提案（画像素材が必要など）は除いてください。
